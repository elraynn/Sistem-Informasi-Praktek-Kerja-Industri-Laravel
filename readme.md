# Sistem Informasi Praktek Kerja Industri

Web app for managing SMK (vocational school) student internships (Prakerin/PKL), built with Laravel.

Handles the full internship workflow: student, teacher and industry partner records, internship period setup, application letters, internship requests with committee and industry-side approval, and report submission/download.

## Roles

- Admin/committee (panitia) — manages students, teachers, industry partners, periods, and confirms internship requests
- Student — applies for an internship placement, checks status, submits reports
- Industry partner — accepts/rejects incoming placement requests

## Stack

PHP, Laravel, MySQL
